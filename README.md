# Lumina — Öğrenme Stilleri ve Bilişsel Gelişim Platformu

Lumina, bireylerin kendi öğrenme modellerini keşfetmelerini sağlayan, interaktif 3D nöral simülasyon destekli bir web platformudur.

---

## 📌 Ana Hatlar

* **5 Temel Öğrenme Modeli:** Görsel, işitsel, yazarak, okuyarak ve deneyimsel modellerin analizi.
* **3D Nöral Görselleştirme:** Bilişsel odak alanlarını temsil eden etkileşimli 3D beyin modeli.
* **Kullanıcı Paneli:** Bireysel test sonuçları ve kişiselleştirilmiş rehberlik alanı.
* **Karanlık / Aydınlık Mod:** Sistemle ve tercihlerle uyumlu tema desteği.
* **Gizlilik & KVKK:** Üçüncü taraf takip çerezi barındırmayan şeffaf altyapı.

---

## 🛠️ Teknolojiler

* **Backend:** FastAPI (Python)
* **Frontend:** HTML5, CSS3, JavaScript
* **3D Görselleştirme:** Three.js

---

## 🚀 Çalıştırma

```bash
pip install -r requirements.txt
uvicorn server:app --reload
```
